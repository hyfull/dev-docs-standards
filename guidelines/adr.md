# 架构决策记录（ADR）

在 `docs/decisions/` 为每个重要且影响持续较久的选择写一份记录，文件名采用 `NNNN-short-title.md`。编号在项目内递增；一个编号只对应一项决定。

建议结构：

1. 背景：问题、约束及目标。
2. 选项：认真考虑过的替代方案和关键取舍。
3. 决定：所选方案和适用范围。
4. 后果：收益、代价、风险及后续行动。
5. 状态与依据：当前状态、日期、相关实现和验证链接。

已有决定改变时，新增 ADR 并从旧记录链接到新记录，保留历史脉络。[ADR 模板资料](https://adr.github.io/adr-templates/)提供了可参考的更完整格式。
